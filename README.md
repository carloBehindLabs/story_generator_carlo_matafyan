# Mad Libs Generator

## Description

This is a simple Python program that generates fun and creative stories based on user input. The user selects one of three templates and fills in different types of words (nouns, verbs, adjectives, etc.). The program then creates a unique story using those inputs.

## Features

* Choose between 3 different story templates:

  * Hospital Story
  * Camping Story
  * Castle Story
* Interactive user input
* Randomized and creative storytelling experience
* Beginner-friendly Python code

## How to Run

1. Download or copy the Python file.
2. Open a terminal or command prompt.
3. Navigate to the folder containing the file.
4. Run the program using:

   ```
   python filename.py
   ```
5. Follow the on-screen instructions.

## How It Works

1. The user selects a template by entering a number (1–3).
2. The program prompts the user to enter different types of words.
3. The program inserts those words into a predefined story template.
4. The completed story is displayed on the screen.

## Example

```
Choose a template:
1 - Hospital Story
2 - Camping Story
3 - Castle Story

Enter the number of your choice: 2
Enter a person's name: Alex
Enter a noun: backpack
...
```

## Notes

* The program uses only `print()` and `input()` functions as required.
* No advanced functions or libraries are used to keep the code simple.
* Great for beginners learning Python basics like variables and user input.
